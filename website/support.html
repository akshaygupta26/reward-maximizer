Support

Reward Maximizer — Chrome extension support

Contact Support

The fastest way to get help is by email: rewardmaximizer@gmail.com.

We aim to respond within 7 business days but make no guarantees about response times, resolution of issues, or availability of support.

Report a Bug

Reward Maximizer is open source. Bug reports and feature requests are welcome on GitHub:

  • GitHub Issues — report a problem or request a feature
  • GitHub Repository — read the source code

When reporting a sync problem with a bank portal, please include the portal name (for example, Amex or Chase) and what happened — no account numbers, passwords, or other sensitive details.

Common Questions

  • Which banks are supported? American Express, Chase, Citi, Capital One, Discover, Bank of America, and US Bank, plus Rakuten as a cashback portal for stacking.
  • Is my data private? Yes — everything is stored locally in your browser. There are no accounts, servers, or analytics. See the Privacy Policy.
  • Is it free? Yes. There is no premium tier, no paywalled features, and no ads.
