## Updating the Website

To update the website content:

1. Make changes to files in `/website/` folder
2. Go to https://app.netlify.com/drop
3. Drag and drop the `/website/` folder again
4. Netlify will give you a NEW random URL
5. Update this file with the new URLs
6. Update Chrome Web Store listing with new Privacy Policy URL

**Important:** The URL will change each time you use Netlify Drop. To keep the same URL:
- Create a free Netlify account
- Claim your site
- Future updates will keep the same URL
